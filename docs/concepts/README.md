# Concepts

One page per concept learned while building this project, written as it is learned. Together they
become the onboarding course for whoever joins next.

Each page is short and follows this shape:

```
# <Concept>

**In one sentence.** <what it is>

**Like something you know.** <relate it to a familiar domain, and say where the comparison breaks>

**Where it shows up here.** <the files or modules, with paths>

**Watch out for.** <the mistake it invites>
```

Write for a reader who has never seen the project.
