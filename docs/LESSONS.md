# Lessons

This project's own lessons. Each is dated, tells what happened, and ends in a rule.
`PRINCIPLES.md` holds the inherited ones. This file holds the ones learned here.

When a lesson should never repeat, add a guard test and a one-line rule in `CLAUDE.md` pointing at it.

## Format

```
## N. <the rule, as a short sentence> (YYYY-MM-DD)

**What happened.** <the story, plainly: what we expected, what happened, how we found out>
**Why.** <the mechanism, measured if possible>
**Rule.** <what we do now>
**Guard.** <the test that enforces it, if any>
```

If a lesson turns out to be wrong, correct it in place with a dated note. Don't delete it.
