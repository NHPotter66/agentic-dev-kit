# What to watch

Claims this project makes that are **not yet proven at their level**. Check here first when someone
asks "is X working?".

Each row names:

- the claim;
- a check anyone can run;
- what failure would look like.

Remove a row when the claim is proven at its level, and say how in `TIMELINE.md`.

## Format

```
### W1 — <the claim, in one sentence>
**Level needed:** staged | real · **Proven so far:** static · **Added:** YYYY-MM-DD
**Check:** <command or steps anyone can run>
**Fails if:** <what you'd see if the claim is false>
**Blocked on:** <optional, what has to happen before it can be checked>
```
