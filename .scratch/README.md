# .scratch: maps and tickets

One directory per effort:

```
.scratch/<effort>/
  map.md                    where this effort is going (from TEMPLATE-map.md)
  issues/01-short-name.md   one file per ticket (from TEMPLATE-ticket.md), numbered from 01
```

Ticket status is the `Status:` line at the top of each file. Never put several tickets in one file.

Later these may move to GitHub Issues. The map and specs stay here, next to the code.
